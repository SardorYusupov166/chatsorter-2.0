# ChatSorter 2.0.0-alpha.4 — Minecraft 1.21.11

Создан **mlpgod** для MigosMC и других серверов Minecraft. Это ранняя разработка ChatSorter 2.0 на основе стабильных исходников 1.4.5. Сейчас ведётся только ветка Minecraft **1.21.11**.

## Текущий этап

- Добавлена единая лента сообщений с устойчивыми UUID для записей.
- Записи несут сервер, сессию, исходное время, отправителя, категории, исходный Minecraft `Text` и идентификатор диалога.
- Объединённые повторы остаются одной строкой интерфейса, но сохраняют исходные записи и их отдельные ID.
- Хранилище предоставляет общий источник для категорий и будущих панелей.
- Формат истории расширен дополнительными полями; старые JSON-массивы 1.4.5 продолжают загружаться, отсутствующие ID создаются при миграции в памяти и сохраняются при следующей записи.
- Добавлены пользовательские Regex-фильтры: категории, поля «текст / отправитель / встроенная категория», режимы `COPY` и `MOVE`, приоритет и пробный тест.
- Категории пользовательских правил можно включать одновременно со встроенными. В строке интерфейса есть постраничная навигация.
- Regex выполняется через RE2/J, с ограничениями длины выражения и проверяемого текста. Вложенная библиотека включается в Fabric JAR.
- Правила и включённые категории сохраняются в `config/chatsorter/filters.properties`; параметры общие для всех серверов.
- Добавлены закладки: правый клик по сообщению → «Добавить в избранное». Закладки хранятся отдельно для каждого сервера и доступны во включаемой вкладке «Избранное».
- Закладки сохраняют исходные сообщения повторов. Если запись уже исчезла из локальной истории, избранное показывает сохранённую копию с пометкой.
- Добавлено множественное выделение сообщений: Ctrl+Click переключает отдельную строку, Shift+Click выбирает диапазон, Ctrl+Shift+Click добавляет диапазон.
- Ctrl+A выделяет сообщения текущего отображения после фокуса на области истории; поиск и активные фильтры ограничивают выбор видимым набором.
- Панель выделения копирует выбранный текст, текст со временем или отправителями, а также экспортирует выбор в TXT и JSON в `config/chatsorter/exports`.
- Для объединённых повторов можно переключить копирование и TXT-экспорт с одной отображаемой строки на все исходные сообщения; JSON сохраняет исходные записи и их ID.
- Выбранные строки отмечаются голубым индикатором. Обычные клики по интерактивному тексту не перехватываются.
- Исправлен индекс пользовательских категорий в отрисовке переключателей после вкладки «Избранное».

Остальные функции 2.0 ещё разрабатываются: автоматические вкладки ЛС, подсветка и панели.

## План

1. Закончить базовый слой сообщений и миграцию истории.
2. Добавить подсветку и автоматические вкладки личных сообщений.
3. Добавить вкладки личных диалогов, закладки и выделение с экспортом.
4. Реализовать независимые панели и проверить производительность.
5. Провести приёмочные проверки и подготовить релиз 2.0.

Переключатели нескольких категорий в одном окне, объединение повторов, восстановление истории, поиск, расширенное копирование, звуковые уведомления и темы остаются частью базовой функциональности.

## Установка и сборка

Это alpha-сборка для разработки, а не готовый релиз для игры. Требуются Minecraft 1.21.11, JDK 21, Fabric Loader и Fabric API для 1.21.11.

Сборка: `gradle build`  
Ожидаемый JAR: `build/libs/chatsorter-2.0.0-alpha.4.jar`
